# Project Desk Preview

Mobile-first project management prototype.

- Open `index.html` in a browser.
- Project cards are the top-level entry point.
- Quick entry is a one-question-at-a-time form.
- R&D projects have the fixed TL categories: System, Mechanical, Hardware, BSW, ASW.
- Sales delivery projects have IPD checkpoints M1, M2, M3, M4 and Q3; M3 expands into task planning.
- Export uses UTF-8 CSV with BOM, which WPS and Excel can open.
- Data is currently saved to browser localStorage. This preview does not yet synchronize data between devices; cloud database integration is a separate step.
